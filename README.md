 📝 Gestor de Tareas en Consola (CLI)

Un programa interactivo desarrollado en Python para gestionar tareas diarias, permitiendo organizar pendientes con fechas de vencimiento.

 🚀 Características Principales

* Menú Interactivo: Navegación sencilla mediante opciones numéricas.
* Gestión de Datos:** Permite agregar tareas con fecha y visualizarlas en lista.
* Eliminación Precisa:** Sistema para borrar tareas seleccionando su índice.
* Validación de Errores (Robustez):
    * Uso de `try-except` para manejar entradas no numéricas.
    * Validación de rangos para evitar opciones inválidas en el menú.
    * Prevención de cierres inesperados del programa.
 🛠️ Tecnologías y Conceptos Aplicados

Este proyecto fue creado para poner en práctica conceptos fundamentales de programación y control de versiones:

* Lenguaje: Python 3
* Estructuras de Datos: Listas (`[]`) y Tuplas (para almacenar pares Tarea-Fecha).
* Control de Flujo: Bucles `While True` y condicionales `If-Elif-Else`.
* Manejo de Excepciones: Bloques `try-except` y `ValueError`.
* Control de Versiones: Git y GitHub (Ramas, Merges y Pull Requests).
